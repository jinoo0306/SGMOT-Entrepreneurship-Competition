# Clova Note Clone - 클로바노트 클론

네이버 클로바노트를 모방한 정적 웹 애플리케이션입니다. 텍스트 노트 작성, 음성 녹음(UI), AI 요약(UI) 기능을 갖춘 모던한 노트 앱 인터페이스를 제공합니다.

## 🎯 프로젝트 목표

네이버 클로바노트의 주요 UI/UX를 클론코딩하여 퍼블리싱 완성도를 높이고, 실제 노트 앱의 인터랙션을 구현합니다.

## ✨ 주요 기능

### ✅ 완료된 기능

#### 1. 노트 관리
- ✅ 새 노트 생성 및 저장
- ✅ 노트 제목/내용 실시간 편집
- ✅ 노트 목록 표시 (그리드/리스트 뷰)
- ✅ 노트 검색 UI
- ✅ 노트 삭제 기능
- ✅ 즐겨찾기 토글
- ✅ 컨텍스트 메뉴 (우클릭 메뉴)

#### 2. 리치 텍스트 에디터
- ✅ 굵게, 기울임, 밑줄 서식
- ✅ 글머리 기호, 번호 매기기
- ✅ 링크 삽입
- ✅ 이미지 삽입 (URL)
- ✅ 문자 수 카운트
- ✅ 자동 저장 표시

#### 3. 녹음 기능 (UI Only)
- ✅ 녹음 시작/중지 인터페이스
- ✅ 녹음 타이머 표시
- ✅ 음성 → 텍스트 변환 시뮬레이션
- ✅ 녹음 상태 애니메이션

#### 4. AI 요약 기능 (UI Only)
- ✅ 요약 생성 버튼
- ✅ 요약 내용 표시
- ✅ 키워드 추출 표시

#### 5. 사이드바 네비게이션
- ✅ 모든 노트, 즐겨찾기, 녹음 노트, 휴지통 메뉴
- ✅ 폴더 관리 UI
- ✅ 노트 개수 표시
- ✅ 사이드바 토글 (모바일)

#### 6. 반응형 디자인
- ✅ 데스크톱 (1200px+)
- ✅ 태블릿 (768px ~ 1200px)
- ✅ 모바일 (< 768px)

## 🚀 시작하기

### 실행 방법

1. 프로젝트 파일 다운로드
2. `index.html` 파일을 웹 브라우저로 열기
3. 또는 로컬 서버 실행:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Node.js (http-server)
   npx http-server
   ```
4. 브라우저에서 `http://localhost:8000` 접속

## 🎨 디자인 특징

### 컬러 팔레트
- **Primary**: `#00C73C` (네이버 그린)
- **Background**: `#F8F9FA` (밝은 회색)
- **Text**: `#212529` (다크 그레이)
- **Border**: `#DEE2E6` (라이트 그레이)

### 타이포그래피
- 시스템 폰트 스택 (Apple SD Gothic Neo, Malgun Gothic 등)
- 반응형 폰트 크기
- 적절한 행간 (line-height: 1.5 ~ 1.8)

### 레이아웃
- 3단 레이아웃 (사이드바 + 노트 리스트 + 에디터)
- Flexbox 기반 구조
- 고정 헤더 (60px)

## 💻 기술 스택

- **HTML5**: 시맨틱 마크업
- **CSS3**: Flexbox, Grid, CSS Variables, Transitions
- **JavaScript (ES6+)**: Vanilla JS, DOM Manipulation
- **Font Awesome 6**: 아이콘 라이브러리

## 🔧 주요 함수

### JavaScript 주요 함수 목록

```javascript
// 노트 관리
createNewNote()          // 새 노트 생성
selectNote(noteId)       // 노트 선택 및 표시
deleteNote(noteId)       // 노트 삭제
renderNoteList()         // 노트 목록 렌더링

// 에디터
handleTitleChange(e)     // 제목 변경 처리
handleContentChange()    // 내용 변경 처리
updateCharCount()        // 문자 수 업데이트

// 탭 전환
switchTab(tabName)       // 작성/녹음/요약 탭 전환

// 녹음 기능
startRecording()         // 녹음 시작 (시뮬레이션)
stopRecording()          // 녹음 중지
updateRecordingTime()    // 녹음 시간 업데이트

// UI 인터랙션
toggleSidebar()          // 사이드바 토글
showContextMenu(e, id)   // 컨텍스트 메뉴 표시
generateSummary()        // 요약 생성 (시뮬레이션)
```

## ⚠️ 제한사항

### 구현되지 않은 기능 (UI만 있음)

1. **실제 음성 녹음**: Web Audio API 미구현
2. **실제 AI 요약**: AI API 연동 없음
3. **데이터 영속성**: LocalStorage 미사용 (새로고침 시 초기화)
4. **클라우드 동기화**: 서버 연동 없음
5. **사용자 인증**: 로그인/회원가입 없음
6. **파일 첨부**: 실제 파일 업로드 미지원
7. **공유 기능**: 공유 URL 생성 미구현
8. **폴더 관리**: 폴더 생성/삭제/이동 미구현
